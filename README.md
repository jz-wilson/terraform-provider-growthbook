# terraform-provider-growthbook

A Terraform and OpenTofu provider for [GrowthBook](https://www.growthbook.io/),
built on the [Terraform Plugin Framework](https://developer.hashicorp.com/terraform/plugin/framework)
and the shared [growthbook-go](https://github.com/jz-wilson/growthbook-go)
client that also powers the
[Crossplane provider](https://github.com/jz-wilson/provider-growthbook).

```hcl
terraform {
  required_providers {
    growthbook = {
      source = "jz-wilson/growthbook"
    }
  }
}

provider "growthbook" {
  # or GROWTHBOOK_API_KEY / GROWTHBOOK_API_URL
  api_key = var.growthbook_api_key
  api_url = "https://growthbook.example.com/api" # omit for GrowthBook Cloud
}
```

Resources and data sources are documented under `docs/` (generated by
`tfplugindocs` from the schemas and `examples/`).

## Developing

Requires Go (see `go.mod`) and Terraform or OpenTofu.

```bash
make build      # compile
make test       # unit tests
make lint       # golangci-lint
make generate   # regenerate docs/ from schemas and examples
```

Acceptance tests need a live GrowthBook. The compose file and bootstrap
script under `e2e/` start one and mint an API key:

```bash
docker compose -f e2e/docker-compose.yml up -d --wait
export GROWTHBOOK_API_KEY=$(e2e/bootstrap.sh)
export GROWTHBOOK_API_URL=http://localhost:3100/api
make testacc
```

An unlicensed GrowthBook enforces the free plan (one project, no custom
environments) with HTTP 402; tests that need more skip or adapt.

To use a locally built provider, add a `dev_overrides` block to your
`~/.terraformrc` pointing `jz-wilson/growthbook` at `$GOBIN`.
